# Texture sizes

Menu button SVG:
- Canvas: 353 x 97 px
- Button shape inside: about 321 x 65 px
- Keep 16 px transparent space around the shape for glow

HUD textures currently in the project:
- HP background: 222 x 14 px
- Dash bar background: 174 x 10 px
- Special spire background: 12 x 32 px

Fill textures:
- HP-fill.svg: 222 x 14 px
- Dash bar fill: 174 x 10 px
- Special spire fill: 12 x 32 px

The game draws the filling dynamically over these background textures.
